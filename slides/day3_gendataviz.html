Set comparisons: Venn & UpSet

Why Compare Gene Sets?

Common scenarios:

  • Differential expression: Which genes change across conditions?
  • Pathway analysis: Which genes overlap between pathways?
  • Multi-omics: Which features appear in multiple datasets?
  • Comparative genomics: Which genes are shared/unique?

The challenge:

How do you visualize overlaps between 3, 4, 5+ sets clearly?

Two approaches:

Venn diagrams: - ✅ Intuitive for 2-3 sets - ❌ Messy for 4+ sets - Shows all possible intersections

UpSet plots: - ✅ Scales to many sets - ✅ Shows intersection sizes clearly - ✅ More informative than Venn

When to Use Each Method

Feature Venn Diagram UpSet Plot
Best for 2-3 sets 3+ sets
Maximum sets ~4 sets (becomes unclear) 10+ sets easily
Shows sizes Yes (with labels) Yes (bar heights)
Easy to read High (for 2-3 sets) High (any number)
Quantitative Circles not proportional Exact counts shown
Interpretation Quick overview Detailed comparisons

Rule of thumb: Use Venn for ≤3 sets, UpSet for ≥4 sets

UpSet Plots: Better for Multiple Sets

Code:

library(UpSetR)

# Convert list to binary matrix
upset_data <- fromList(gene_sets_5)

# Create UpSet plot
upset(
  upset_data,
  nsets = 5,                    # Number of sets to show
  order.by = "freq",            # Order by frequency
  main.bar.color = cross_colors[1],
  sets.bar.color = cross_colors[3],
  text.scale = 1.5,             # Increase text size
  point.size = 4,
  line.size = 1.5
)

Key concepts: - Bottom bars: Size of each set - Top bars: Size of each intersection - Dots + lines: Which sets contribute to intersection

UpSet Plot Output

Reading: Tallest bar = largest intersection (genes in Exp_1 AND Exp_2 only)

How to Read UpSet Plots

Bottom section:

  • Horizontal bars = set sizes
  • Shows total genes per experiment

Top section:

  • Vertical bars = intersection sizes
  • Height = number of genes

Connection matrix:

  • Single dot: Unique to one set
  • Multiple dots + line: Shared by those sets
  • Empty: Not in that set

Example:

● ━ ●     = Exp_1 AND Exp_3 only
●         = Exp_1 only  
● ━ ● ━ ● = All three

Best Practices

Design guidelines:

For Venn diagrams:

✅ Use for 2-3 sets maximum
✅ Show counts/numbers in regions
✅ Use transparent fills (alpha = 0.3)
✅ Choose contrasting colors
❌ Don’t use for >4 sets

For UpSet plots:

✅ Order by frequency (most common first)
✅ Increase text size for readability
✅ Use consistent colors
✅ Show set sizes on bottom
✅ Limit to top 20-30 intersections

General:

  • Always label your sets clearly
  • Include sample sizes in title/caption
  • Export at high resolution for publication

Phylogenetic trees

What are Phylogenetic Trees?

Definition:

Trees represent evolutionary relationships between species, genes, or sequences

Key components:

  • Tips/leaves: Species or genes
  • Branches: Evolutionary paths
  • Nodes: Common ancestors
  • Branch lengths: Evolutionary distance

Why visualize trees?

  • Show evolutionary relationships
  • Identify gene families
  • Compare species divergence
  • Analyze trait evolution
  • Detect horizontal gene transfer

Common in:

  • Comparative genomics
  • Population genetics
  • Molecular evolution
  • Phylogeography

Tree Layouts: Choose Your View

Layout Best For Shows Time Space Usage Readability
Rectangular Small-medium trees (< 50 tips) Yes Linear High
Circular Large trees, aesthetic No Compact Medium
Radial Medium trees, space-efficient No Compact High
Fan Large trees, semicircular Partial Medium Medium
Unrooted Networks, no root No Variable Low

We’ll explore all of these!

Advanced: ggtreeExtra

What is ggtreeExtra?

Purpose:

Add data layers around phylogenetic trees

What you can add:

  • Heatmaps (gene expression, traits)
  • Bar plots (abundances, counts)
  • Dot plots (presence/absence)
  • Point annotations (categories)
  • Any data visualization!

Why use it?

  • Integrate multi-omics data
  • Show trait evolution
  • Compare gene expression
  • Display metadata visually
  • Publication-quality figures

We’ll use:

  • Manual annotation (most stable)
  • Direct geom placement
  • Works with all ggplot2 versions

Extract y-coordinates for annotations:

# Get tree structure data

# Merge with trait data

head(tip_data[, c("label", "x", "y", "expression", "habitat")])

Example 1: Heatmap Track - Code

Add heatmap using geom_tile:

# Get tree and tip positions
tree_data <- fortify(tree)
tip_data <- merge(tree_data[tree_data$isTip, ],

# Find max x position for placement
max_x <- max(tree_data$x)

# Create plot
ggtree(tree, layout = "circular") +
  geom_tiplab(size = 2.5, offset = 1.5) +
  geom_tile(data = tip_data,

           width = 1, height = 0.8) +
  
  scale_fill_gradientn(colors = cross_colors) +
  xlim(NA, max_x + 4) +  # Extend x-axis for heatmap
  labs(title = "Tree with Expression Heatmap")

Why Circular Plots?

Purpose:

Visualize whole genomes in a compact, intuitive format

What you can show:

  • Chromosome structure
  • Gene density
  • Expression levels
  • Structural variants
  • Synteny between regions
  • Coverage tracks

Advantages:

✅ Compact for large genomes

✅ Easy to spot patterns
✅ Publication favorite
✅ Multiple data layers

Common uses:

  • Genome-wide associations
  • Structural rearrangements
  • Multi-omics integration
  • Comparative genomics

The circlize Package

Key concepts:

Sectors = Chromosomes

Each chromosome is a sector (slice of the circle)

Tracks = Data layers

Add multiple tracks moving outward from center

Links = Connections

Lines connecting regions (structural variants, synteny)

Basic workflow:

  1. Initialize: Set up chromosomes
  2. Add tracks: Gene density, heatmaps, etc.
  3. Add links: Connect regions
  4. Clear: Reset for next plot

Important: Always call circos.clear() after each plot!

Gene arrangements & synteny

What is Synteny?

Definition:

Synteny = Conservation of gene order and chromosomal organization between species or within genomes

Why study synteny?

  • Track chromosomal rearrangements
  • Validate genome assemblies
  • Predict gene functions
  • Identify conserved regions

Types of synteny:

  1. Conserved: Same order, same orientation
  2. Inverted: Same genes, flipped orientation
  3. Disrupted: Rearrangements, insertions, deletions

Why Visualize Gene Arrangements?

Common biological questions:

Evolutionary studies: - Which genes moved? - Where did inversions occur? - What blocks are conserved?

Functional genomics: - Are genes in operons? - Which genes cluster together? - Are pathways co-located?

Genome annotation: - Transfer annotations across species - Identify mobile elements - Find insertion/deletion events

Today we’ll learn: - gggenes for gene-level detail - How to show rearrangements - How to highlight insertions (prophages!)

Exercise 2: Prophage Insertion Analysis

Analyze prophage integration in E. coli:

# Wildtype vs prophage-containing strain
set.seed(123)

ecoli_prophage <- data.frame(
  strain = rep(c("E.coli_K12", "E.coli_Lysogen"), each = 12),
  gene = c(
    # Wildtype genes
    paste0("Gene_", sprintf("%02d", 1:12)),
    # Lysogen: prophage inserted after Gene_06
    c(paste0("Gene_", sprintf("%02d", 1:6)),
      paste0("λ_", c("CI", "Cro", "N", "Q", "Tail")),  # 5 phage genes
      paste0("Gene_", sprintf("%02d", 7:7)))
  ),
  start = c(
    # Wildtype: evenly spaced
    seq(10000, 110000, length.out = 12),
    # Lysogen: disrupted spacing
    c(seq(10000, 60000, length.out = 6),   # Genes 1-6
      seq(62000, 90000, length.out = 5),    # Prophage
      seq(92000, 92000, length.out = 1))    # Gene 7 (shifted)
  ),
  type = c(
    rep("host", 12),
    c(rep("host", 6), rep("prophage", 5), rep("host", 1))
  )
)
ecoli_prophage$end <- ecoli_prophage$start + 
  ifelse(ecoli_prophage$type == "prophage", 5000, 7000)
ecoli_prophage$orientation <- sample(c(1, -1), nrow(ecoli_prophage), 
                                     replace = TRUE)
