Why Reduce Dimensions?

High-dimensional data challenges:

  • Genomic datasets often have thousands of features
  • Difficult to visualize and interpret
  • Computationally expensive

Solution: Dimensionality reduction

  • Compress data to 2-3 dimensions
  • Preserve important patterns and relationships
  • Enable visual exploration

PCA: Theory

Principal Component Analysis

  • Linear method that finds directions of maximum variance
  • Creates orthogonal (uncorrelated) components
  • PC1 explains most variance, PC2 second most, etc.

Best for:

  • Linearly separable data
  • Understanding variance structure
  • Quality control and exploratory analysis
  • Fast computation on large datasets

Key concept: Transforms correlated variables into uncorrelated principal components

UMAP: Theory

Uniform Manifold Approximation and Projection

  • Non-linear method based on manifold learning
  • Preserves both local and global structure
  • Faster than t-SNE for large datasets

Best for:

  • Complex, non-linear relationships
  • Preserving cluster relationships
  • Large datasets (>10,000 cells/samples)
  • General exploratory analysis

Key concept: Models data as a manifold and projects to lower dimensions while preserving topology

t-SNE: Theory

t-Distributed Stochastic Neighbor Embedding

  • Non-linear method focusing on local structure
  • Converts high-dimensional distances to probabilities
  • Excellent at revealing tight clusters

Best for:

  • Cluster visualization and discovery
  • Revealing hidden structure
  • Smaller datasets (<10,000 points)
  • Publications requiring clear separation

Caution:

  • Distances between clusters are not meaningful
  • Different runs produce different layouts (non-deterministic)

Choosing the Right Method

Method Type Speed Preserves Best For Deterministic
PCA Linear Fast Global variance QC, linear relationships Yes
UMAP Non-linear Medium-Fast Local & global structure General exploration, large data No (but reproducible)
t-SNE Non-linear Slow Local neighborhoods Cluster discovery, small data No

Exercise 1: PCA on Gene Expression Data

# 1. Create gene expression matrix (samples × genes)
set.seed(123)
n_samples <- 40
n_genes <- 1000

gene_expr <- matrix(
  rpois(n_samples * n_genes, lambda = 50),
  nrow = n_samples,
  ncol = n_genes
)

# Add column names (gene IDs)
colnames(gene_expr) <- paste0("Gene_", 1:n_genes)

# Create sample metadata
sample_meta <- data.frame(
  sample_id = paste0("Sample_", 1:n_samples),
  condition = rep(c("Control", "Treatment"), each = 20),
  batch = rep(1:4, times = 10)
)

# 2. Perform PCA with scaling
pca_result <- prcomp(gene_expr, scale. = TRUE)
summary(pca_result)

# 3. Extract scores and combine with metadata
pca_df <- pca_result$x |> 
  as.data.frame() |> 
  bind_cols(sample_meta)

# 4. Create PCA plot colored by condition
ggplot(pca_df, aes(x = PC1, y = PC2, 
                   color = condition, 
                   shape = factor(batch))) +
  geom_point(size = 4, alpha = 0.7) +
  stat_ellipse(aes(color = condition)) +
  scale_color_manual(values = c("Control" = "steelblue", 
                                 "Treatment" = "coral")) +
  labs(
    title = "PCA of RNA-seq Data",
    subtitle = "Check for batch effects and treatment separation"
  )

Volcano Plots: Introduction

What is a volcano plot?

  • Combines statistical significance (p-value) with biological significance (fold change)
  • X-axis: log2 fold change (effect size)
  • Y-axis: -log10(p-value) (statistical significance)

Key features:

  • Identifies significantly differentially expressed genes
  • Shows both magnitude and significance of changes
  • Enables labeling of genes of interest

Volcano Plot Anatomy

How to interpret the plot:

  • Top: Most significant genes (low p-value)
  • Right: Upregulated genes (positive fold change)
  • Left: Downregulated genes (negative fold change)
  • Center: Not significantly changed

Typical thresholds:

  • Fold change: |log2FC| > 1 (2-fold change)
  • P-value: p < 0.05 or adjusted p < 0.05
  • Combined: both criteria must be met

# Create 3 treatment comparisons
set.seed(999)
create_comp <- function(name) {
  data.frame(
    gene = paste0("Gene_", 1:1000),
    log2FC = rnorm(1000, 0, 2),
    pvalue = rbeta(1000, 0.1, 1),
    comparison = name
  ) |>
    mutate(padj = p.adjust(pvalue, "BH"),
           log10p = -log10(padj),
           sig = ifelse(abs(log2FC) > 1 & padj < 0.05, "Sig", "NS"))
}

comp_data <- bind_rows(
  create_comp("Treatment A"),
  create_comp("Treatment B"),
  create_comp("Treatment C")
)

# Faceted plot
ggplot(comp_data, aes(x = log2FC, y = log10p, color = sig)) +
  geom_point(alpha = 0.5, size = 1.5) +
  scale_color_manual(values = c("Sig" = "#d1422f", "NS" = "gray80")) +
  facet_wrap(~comparison, ncol = 3) +
  geom_hline(yintercept = -log10(0.05), linetype = "dashed") +
  geom_vline(xintercept = c(-1, 1), linetype = "dashed") +
  labs(title = "Multiple Treatment Comparisons",
       x = "log2 Fold Change", y = "-log10(Adjusted P-value)") +
  theme_minimal()

Peak Visualization

Peak Visualization: Introduction

What are peaks?

  • Regions of enriched signal in genomic assays
  • ChIP-seq: Protein-DNA binding sites
  • ATAC-seq: Open chromatin regions

What is a karyotype plot?

A karyotype plot visualizes data along real chromosome structures.

  • Chromosomes are drawn to scale
  • Genomic coordinates are preserved
  • Signals are mapped onto physical chromosomes

Typical questions it answers

  • Where do signals cluster in the genome?
  • Are specific chromosomes enriched?
  • Do signals accumulate near chromosome ends?

Heatmaps: Introduction

What are heatmaps?

  • Matrix visualization using color intensity
  • Rows: genes, samples, or features
  • Columns: samples, conditions, or measurements
  • Color: expression level or correlation

Common uses in genomics:

  • Gene expression patterns across samples
  • Sample clustering and relationships
  • Correlation matrices
  • Methylation patterns

Why Use Heatmaps?

Advantages:

  • Visualize thousands of genes simultaneously
  • Reveal patterns and clusters
  • Show hierarchical relationships
  • Compare multiple conditions at once

Key components:

  • Dendrograms (clustering trees)
  • Color scales (sequential or diverging)
  • Row/column annotations
  • Z-score normalization

# Simulate gene expression matrix
set.seed(123)
n_genes <- 50
n_samples <- 10

expr_matrix <- matrix(
  rnorm(n_genes * n_samples, mean = 50, sd = 20),
  nrow = n_genes,

)

# Add tissue-specific patterns

# Create heatmap
library(pheatmap)

         scale = "row",

         clustering_distance_cols = "euclidean",

Venn Diagrams: Introduction

What are Venn diagrams?

  • Show overlaps between sets
  • Compare gene lists from different experiments
  • Visualize shared and unique elements
  • Maximum 3-4 sets for clarity

Common genomics applications:

  • DEGs across multiple comparisons
  • Overlapping peaks from ChIP-seq
  • Common genes in pathways
  • Shared variants between samples

Creating Gene Sets: Code

UpSet Plots: Introduction

Why UpSet plots?

  • Better than Venn diagrams for >3 sets
  • Show exact intersection sizes
  • Clear visualization of complex overlaps
  • Scalable to many sets

When to use:

  • Comparing 4+ gene lists
  • Multiple tissue comparisons
  • Multi-condition experiments
  • Complex set relationships

Phylogenetic trees

Why Visualize Phylogenetic Trees?

Understanding evolutionary relationships:

Key applications:

  • Show species relationships and divergence
  • Identify conserved and divergent lineages
  • Detect horizontal gene transfer
  • Guide taxonomic classification
  • Compare gene family evolution

Visualization challenges:

  • Trees can have hundreds to thousands of tips
  • Multiple layout options for different insights
  • Need to highlight specific clades or features
  • Integrate additional data (traits, geography, expression)

Most common: Rectangular (left) for detailed analysis, Circular (right) for compact display

Best Practices for Tree Visualization

Design tips:

1. Choose layout wisely

  • Small trees (<50 tips): Rectangular with labels
  • Large trees (50-200): Circular or fan
  • Very large (>200): Consider collapsing clades

2. Use color strategically

  • Highlight functional groups or clades
  • Color by metadata (geography, phenotype)
  • Use consistent color schemes across figures

3. Integrate data thoughtfully

  • Add heatmaps for quantitative traits
  • Use symbols for categorical data
  • Don’t overcrowd with too many layers

Interactive Trees with ggtree

Export for interactive exploration:

library(plotly)

# Create tree
p <- ggtree(tree) + geom_tiplab(size = 3)

# Convert to interactive
ggplotly(p)

Advantages:

  • Zoom into specific clades
  • Hover for tip information
  • Toggle layers on/off
  • Suitable for web reports and supplementary materials
